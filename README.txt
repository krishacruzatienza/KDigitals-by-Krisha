KDIGITALS — MODERN ANIMATED WEBSITE

FILES
index.html: page content and your links
styles.css: responsive layout, colors, and animations
script.js: scroll reveals, card tilt, progress bar, and motion controls
kdigitals-logo.jpg: your logo
krisha-photo.jpg: your portrait
assets/: Raket.ph, Gumroad, and TikTok logo images

PREVIEW
Extract the ZIP, keep all files together, and open index.html.
No installation or build command is required.

UPDATE YOUR EXISTING GITHUB WEBSITE
Open your kdigitals repository on GitHub.
Choose Add file > Upload files and upload ALL website files and the assets folder listed above.
Replace the matching filenames and commit to your Pages publishing branch.
Do not upload the ZIP itself or put the files inside an extra folder.
Keep Pages set to main / (root) if that is your existing publishing source.
Your GitHub website updates after its Pages deployment completes.

MOTION
Floating accents, moving ribbon, card hover/tilt, and scroll reveals are included.
Use Pause motion to pause animation. Device reduced-motion settings disable animations.
Touch devices do not use pointer tilt.

EDITING
Change text and profile links in index.html, styles in styles.css, and interactions in script.js.
Replace krisha-photo.jpg to change your portrait.

RESPONSIVE UPDATE
Includes a native mobile menu, service details, buying/request steps, expandable FAQs, and a contact section. Upload all files and the assets folder together.
